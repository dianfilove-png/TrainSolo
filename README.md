# TrainSolo

Трекер тренировок и питания в виде RPG-игры. Твой герой прокачивается вместе с тобой:
записывай упражнения и еду, выполняй ежедневные задания, получай опыт и поднимай ранг от **E** до **S**.

## Возможности

- **Аватар с мышцами** (вид спереди и сзади). Цвет показывает, когда мышца получала нагрузку:
  - 🔴 **красный** — тренировалась сегодня;
  - 🟡 **жёлтый** — вчера, восстанавливается;
  - 🟢 **зелёный** — восстановилась (по умолчанию все мышцы зелёные).

  Нажми на мышцу — увидишь, когда она работала и когда будет готова.
- **Тренировки**: каталог из 40+ упражнений с основными и вспомогательными мышцами, подходы/повторы/вес или время/дистанция для кардио, журнал по дням.
- **Программы**: Full Body для новичка, Push/Pull/Legs, Верх/Низ, Дома без железа, Кардио и «Путь Охотника» (100 отжиманий, 100 подъёмов корпуса, 100 приседаний и 10 км бега). У активной программы — план на день с чек-листом.
- **Питание**: приёмы пищи, каталог продуктов с пересчётом по граммам, ручной ввод, недавние продукты. Дневная норма калорий и БЖУ по формуле Миффлина — Сан Жеора с учётом активности и цели.
- **Игровая механика**: опыт (10 XP за подход, 2 XP за минуту кардио, 5 XP за запись еды), уровни и ранги E → D → C → B → A → S, характеристики героя (СИЛ, ВЫН, ДИС, ЖИЗ), серия активных дней, три ежедневных задания и 10 достижений.
- Все данные хранятся на телефоне (AsyncStorage), интернет и регистрация не нужны.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npx expo start
```

Отсканируй QR-код приложением **Expo Go** (Android / iOS) — приложение откроется на телефоне.
Можно открыть и в браузере: `npx expo start --web`.

Сборка APK / IPA — через [EAS Build](https://docs.expo.dev/build/introduction/): `npx eas-cli@latest build`.

## Разработка

```bash
npm test           # юнит-тесты игровой логики (Jest)
npm run typecheck  # проверка типов TypeScript
npm run lint       # ESLint (expo lint)
```

Стек: Expo SDK 57, React Native, Expo Router, react-native-svg, TypeScript.

```
src/
  app/          экраны (Expo Router): Герой, Тренировка, Программы, Питание, Профиль, страница программы
  components/   аватар (BodyMap + контуры мышц), модальные окна, UI-компоненты
  data/         мышцы, упражнения, программы, продукты
  logic/        восстановление мышц, опыт и уровни, задания, достижения, питание, статистика
  store/        состояние приложения и сохранение на устройстве
```

## Сборка APK

GitHub Actions (`.github/workflows/android-apk.yml`) собирает APK при каждом push:
вкладка **Actions** → последний запуск → артефакт **TrainSolo-apk**.
Если запушить тег (`git tag v1.0.1 && git push origin v1.0.1`), APK появятся в разделе **Releases** — их можно скачать прямо с телефона.

- `TrainSolo-arm64-v8a.apk` — для большинства телефонов;
- `TrainSolo-armeabi-v7a.apk` — для старых 32-битных.
