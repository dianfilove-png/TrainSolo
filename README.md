# TrainSolo

Трекер тренировок и питания для Android в виде RPG-игры. Твой герой прокачивается вместе с тобой:
записывай упражнения и еду, выполняй ежедневные задания, получай опыт и поднимай ранг от **E** до **S**.

Нативное приложение на Kotlin + Jetpack Compose, APK весит около 1,3 МБ. Android 8.0+.

## Возможности

- **Аватар с мышцами** (вид спереди и сзади). Цвет показывает, когда мышца получала нагрузку:
  - 🔴 **красный** — тренировалась сегодня;
  - 🟡 **жёлтый** — вчера, восстанавливается;
  - 🟢 **зелёный** — восстановилась (по умолчанию все мышцы зелёные).

  Нажми на мышцу — увидишь, когда она работала и когда будет готова.
- **Тренировки**: 42 упражнения с основными и вспомогательными мышцами, подходы/повторы/вес или время/дистанция для кардио, журнал по дням.
- **Программы**: Full Body для новичка, Push/Pull/Legs, Верх/Низ, Дома без железа, Кардио и «Путь Охотника» (100 отжиманий, 100 подъёмов корпуса, 100 приседаний и 10 км бега). У активной программы — план на день с чек-листом.
- **Питание**: приёмы пищи, каталог продуктов с пересчётом по граммам, ручной ввод, недавние продукты. Норма калорий и БЖУ по формуле Миффлина — Сан Жеора.
- **Игровая механика**: опыт, уровни и ранги E → S, характеристики героя, серия активных дней, три ежедневных задания и 10 достижений.
- Все данные хранятся на телефоне, интернет и регистрация не нужны.

## Сборка

Нужны JDK 17+ и Android SDK (platform 36).

```bash
./gradlew testDebugUnitTest   # тесты логики и прогон всех экранов (Robolectric)
./gradlew assembleRelease     # APK: app/build/outputs/apk/release/app-release.apk
```

Тест экранов сохраняет скриншоты в `app/build/screens/`.

GitHub Actions (`.github/workflows/android-apk.yml`) собирает APK при каждом push: вкладка **Actions** → запуск → артефакт **TrainSolo-apk**.
Если запушить тег (`git tag v2.0.1 && git push origin v2.0.1`), APK появится в **Releases** — его можно скачать прямо с телефона.

APK подписан стандартным отладочным ключом (`app/debug.keystore`) — подходит для установки на свой телефон; для Google Play нужен собственный ключ.

```
app/src/main/java/com/trainsolo/app/
  model/   модели данных
  data/    мышцы, упражнения, программы, продукты
  logic/   восстановление мышц, опыт и уровни, задания, достижения, питание, статистика
  store/   состояние приложения и сохранение (SharedPreferences + JSON)
  ui/      экраны Compose, аватар (BodyMap), компоненты
```
